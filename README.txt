DEPLOY
1. Back up your existing repository if desired.
2. Extract ZIP. Upload the CONTENTS of the extracted folder (not the folder itself) into the repository root of Sepulchrebot/sepulchrebot.github.io.
3. In GitHub, replace same-named files and COMMIT ALL files, including assets/ images and style.css.
4. Wait until Settings > Pages shows a successful deployment.
5. Check https://sepulchrebot.github.io/assets/sepulchre-banner.webp and /assets/sepulchre-emblem.webp directly in your browser.
6. Hard refresh website (Ctrl + Shift + R).
