# Sepulchre website

Static single-page site for the Sepulchre Discord bot, served by GitHub Pages at https://sepulchre.lol.

- `index.html` is the whole site (pages are hash routes such as `/#commands`).
- Old clean URLs (`/privacy/`, `/terms/`, `/refunds/`, `/commands/` and so on) redirect to the matching page.
- `bot-stats.json` and `commands-data.json` are kept as data files.
- `CNAME` holds the custom domain. Do not delete it.
